# The one prompt

The agent was given exactly this single prompt — nothing else — and built the
game in `game.html` from it:

> Build a tiny browser game: a neon spaceship at the bottom of the screen
> dodges falling asteroids with arrow keys, score +1 per asteroid dodged,
> 3 lives, game over screen, press R to restart.

The video (`video.mp4`, next to this repo) shows this prompt on screen, the
agent working, and the finished game running.
